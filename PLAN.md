2. `[x]` **Inventory Pluto's pragmas.** All 29 convertible benchmarks converted and compiled via `compile.sh` (adi fails in Clan: syntax error line 81, as expected). Only three pragma forms exist:
   - `#pragma ivdep` + `#pragma vector always` (always paired, 412×, in all 29 benchmarks, on vectorizable `lbv..ubv` innermost loops);

Calibration on jacobi-2d: even `polycc --identity --notile --noparallel` output differs from the original at the binary level (133 diff lines; self-check orig-vs-orig is identical). The guilty constructs in Pluto's untransformed output: scop guard `if ((_PB_N >= 3) && (_PB_TSTEPS >= 1))`, iterator decls `int t1..t7; register int lbv, ubv;`, hoisted `lbv/ubv` bounds, rewritten index expressions (`A[t4][1+t6]`), and `ivdep`/`vector always` pragmas.
